# YOLOv8 License Plate Detector - Training Guide

## Overview

This is a comprehensive training pipeline for a YOLOv8 License Plate Detector optimized for:
- **Training**: NVIDIA RTX 2000 Ada GPU (11GB VRAM)
- **Deployment**: NVIDIA Jetson Orin Nano
- **Task**: Detect license plates in Indian vehicles

## Detailed Usage

### Training

```bash
python training/train.py [OPTIONS]

Options:
  --resume TEXT           Resume from checkpoint
  --epochs INTEGER        Override epochs (default: 100)
  --batch-size INTEGER    Override batch size (default: 32)
```

**Example:**
```bash
# Train with custom epochs
python training/train.py --epochs 150

# Resume from checkpoint
python training/train.py --resume models/plate_detector/last.pt
```

### Evaluation

```bash
python training/evaluate.py [OPTIONS]

Options:
  --model TEXT            Model path (default: best.pt)
  --data TEXT             Data.yaml path
  --device INTEGER        GPU device ID (default: 0)
  --infer-images TEXT     Run inference on image folder
  --output-dir TEXT       Output directory for predictions
```

**Example:**
```bash
# Evaluate on test set
python training/evaluate.py

# Evaluate and generate predictions
python training/evaluate.py --infer-images dataset/test/images
```

### Prediction

```bash
python training/predict.py --source SOURCE [OPTIONS]

Options:
  --source TEXT           Image, folder, video, or 'webcam' (REQUIRED)
  --model TEXT            Model path (default: best.pt)
  --output TEXT           Output directory
  --conf FLOAT            Confidence threshold (default: 0.5)
  --device INTEGER        GPU device ID (default: 0)
  --skip-frames INTEGER   Skip N frames in video (default: 1)
  --duration INTEGER      Webcam duration in seconds (default: 30)
```

**Examples:**
```bash
# Single image
python training/predict.py --source image.jpg

# Folder of images
python training/predict.py --source dataset/test/images --output predictions/

# Video
python training/predict.py --source video.mp4 --skip-frames 5

# Webcam (30 seconds)
python training/predict.py --source webcam --duration 30
```

## Training Configuration

### Model Selection: YOLOv8s vs YOLOv8n

**YOLOv8s (Selected)** ✓
- Parameters: 11.2M
- Model size: 22.5 MB
- Inference: 2-3 ms (GPU), 10-15 ms (Jetson)
- Accuracy: Best for production
- Rationale: Better accuracy (5-10% mAP improvement) justifies slight performance trade-off

**YOLOv8n** (Alternative)
- Parameters: 3.2M
- Model size: 6.3 MB
- Inference: 1-2 ms (GPU)
- Accuracy: Good for ultra-lightweight
- Use case: When minimal latency is critical

### Hyperparameters (Optimized)

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Epochs | 100 | Sufficient for convergence with early stopping |
| Batch Size | 32 | Fits RTX 2000 with margin |
| Image Size | 640x640 | Standard YOLO size |
| Optimizer | SGD | Better convergence for YOLO |
| Learning Rate | 0.01 → 0.01 | Cosine annealing |
| Momentum | 0.937 | Standard for SGD |
| Early Stopping | 20 epochs | Stop if no improvement |
| Mixed Precision | Enabled | Faster training, less memory |
| Workers | 8 | Efficient data loading |

### Data Augmentation (License Plate Optimized)

| Augmentation | Value | Rationale |
|--------------|-------|-----------|
| Rotation | ±10° | Real-world viewing angles |
| Translation | ±10% | Plate positioning variation |
| Scale | 85-115% | Vehicle distance changes |
| Flip LR | 50% | Symmetric Indian plates |
| HSV-H | ±1.5% | Lighting conditions |
| HSV-S | ±30% | Color variation |
| HSV-V | ±30% | Brightness/contrast changes |
| Mosaic | 100% | 4-image combinations |
| MixUp | 10% | Blended images |

**Avoided Augmentations:**
- Motion Blur (destroys text clarity)
- Gaussian Blur (harmful for OCR)
- Cutout/Erasing (dangerous for small objects)

## Troubleshooting

### Out of Memory (OOM)
```python
# In config.py, change:
TRAINING_CONFIG["batch_size"] = 16  # Reduce batch size
TRAINING_CONFIG["cache"] = False    # Disable RAM caching
```

### Slow Training
```bash
# Ensure GPU is being used
nvidia-smi

# Increase workers
TRAINING_CONFIG["workers"] = 12
```

### Model Not Converging
```python
# Try different learning rate
TRAINING_CONFIG["lr0"] = 0.001  # Lower
TRAINING_CONFIG["epochs"] = 150  # Longer training
```

### Poor Accuracy
1. Check dataset quality: `python training/dataset_validator.py`
2. Visualize augmentations in training output
3. Try different augmentation settings
4. Collect more diverse training data

## Deployment on Jetson Orin Nano

### Prerequisites
```bash
# On Jetson, install NVIDIA JetPack PyTorch wheel first if available.
# The standard PyPI torch packages may not provide Jetson CUDA support.
export TORCH_INSTALL_URL="https://developer.download.nvidia.cn/compute/redist/jp/v72/pytorch/<torch-wheel-file>.whl"
python3 -m pip install --no-cache-dir "$TORCH_INSTALL_URL"

# Then install the rest of the Jetson requirements.
pip install -r requirements-jetson.txt

# For ONNX inference
pip install onnxruntime

# Optional: GPU acceleration when onnxruntime-gpu is available
pip install onnxruntime-gpu
```

> If you see a warning like:
> `No published PyTorch CUDA builds for release 2.13.0+cu132 support this GPU`,
> it means the installed wheel is not compiled for Jetson Orin's compute capability
> 8.7. This warning can appear even when `torch.cuda.is_available()` is True.
> Prefer a JetPack-specific NVIDIA wheel built for Orin 8.7, or use ONNX/TensorRT
> for production deployment if no compatible PyTorch wheel is available.

### Transfer Model
```bash
# Export model
python training/export.py --format onnx --include-guide

# Transfer to Jetson
scp models/plate_detector/best.onnx jetson@jetson_ip:/home/ubuntu/models/
```

### Run Inference on Jetson
```python
import onnxruntime as ort
import cv2
import numpy as np

# Load model
session = ort.InferenceSession('best.onnx')

# Prepare image (640x640)
image = cv2.imread('plate.jpg')
image_resized = cv2.resize(image, (640, 640))
image_input = np.expand_dims(
    image_resized.transpose(2, 0, 1), 0
).astype(np.float32) / 255.0

# Run inference
outputs = session.run(None, {'images': image_input})
```
